## 🧭 Executive Overview & Platform Mission

In enterprise drone operations, customer success is not merely answering support tickets—it is **protecting recurring revenue, defending operational credibility, and proving clear economic ROI**. 

When an industrial customer considers churn, they don't submit an angry cancellation form: **they quietly stop flying drones**. When an enterprise champion departs, the procurement department freezes expansion tenders. And when a surprise residential client drops in with an idle dock and missing installer, the CSM must intervene before residents revolt at the monthly board meeting.

The **FlytBase CSM Command Center** gives Customer Success Managers a unified, high-contrast operational cockpit that fuses:
1. **Live MCP Protocol Data** from upstream simulated enterprise deployments across Accounts A, B, and K.
2. **Autonomous AI Swarm Agents** that monitor fleet telemetry, predict churn, and draft tactical outreach.
3. **Live Twilio Voice Call & Zero-Key WhatsApp Gateway**: Real outbound phone calls and instant WhatsApp click-to-chat links without API keys!
4. **Audit-Grade Financial Receipts** ($588,000 baseline ARR + $14,000 Kestrel Estates backed by legal PO numbers and contract specifications).
5. **Hardware vs. Relationship Separation of Concerns**: Clear boundary between what the CSM solves (commercial trust, client doubt, competitor alternatives) vs. what the Solution Engineer solves (battery degradation, dock roof motor resistance, RTK satellite acquisition).

### 1. The "Pre-Meeting 60-Second Brief" One-Pager
Before dialing Inspector Karen Mbeki or Group Finance Controller Nadia Rahman, a CSM cannot read 15 contract pages. This module provides a rapid, high-impact tactical card:

- **Root Cause & CSM Action Plan:** Automatically identifies whether the drop is caused by hardware, weather, or user hesitation, and specifies the immediate action required.

### Why TypeScript & Next.js over Python for the Command Center:
1. **Unified Type System (Zero Drift):**
   The upstream MCP server exposes JSON payloads for characters, contracts, and signals. With TypeScript, schemas (`Character`, `Deal`, `CallTranscriptFact`, `BlindSpot`) are shared end-to-end across the cache, the API routes, and the React UI with 100% compile-time safety. In Python, maintaining parallel Pydantic and TypeScript models introduces schema drift during rapid hackathon iterations.
2. **Zero-Latency In-Process API Routes:**
   Next.js API route handlers (`/api/data`, `/api/notes`, `/api/twilio/call`, `/api/twilio/message`) execute within the same server runtime with zero serialization hop, eliminating cold-start latency.
3. **Native Streaming & Real-Time SSE:**
   Next.js handles Server-Sent Events (SSE) and asynchronous polling out-of-the-box, ensuring the 60-second MCP sync runs in the background without blocking the UI thread.
4. **Python's Proper Role:**
   Python is optimal for heavy offline machine learning (e.g. training drone battery thermal degradation models). However, for an interactive executive CRM with live data, optimistic UI updates, real-time telephony, and instant PDF generation, Next.js provides unmatched reliability and performance.
